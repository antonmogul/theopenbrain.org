# Temporary section artwork (OPENBRAIN-65)

Chapters without designer artwork can use `sections.art` just as History does. Generated images are **temporary**: a central diagonal hatch band and large mono PLACEHOLDER lettering are baked into every WebP, and `art.placeholder === true` additionally displays “Placeholder image” in the contents and section card. Designer artwork replaces the complete `art` object without `placeholder`.

`node scripts/figures/make-placeholder-section-art.mjs` discovers anonymous-readable published chapters over GET, using `.env`'s publishable key without printing it. It skips designer art and breakout boxes, takes the first figure in paragraph reading order and uses its first image/poster, attempts to capture a Lottie frame on the live reader, and otherwise uses the chapter cover. `--fixture <export.json>` accepts the same `{chapterSlug: {modules, sections, paragraphs, animations}}` shape for repeatable runs or creator-exported drafts. The committed Stress seed describes its otherwise inaccessible draft sections; its figures have no artwork, so these use the neutral chapter cover. No draft authentication or database write is performed.

The generator uses the actual `RAMP_HEX` and module cover resolvers through Vite. History's 1440 × 1920 aspect ratio is retained; Pillow crops and duotones the source, and fonttools reads the bundled IBM Plex Mono WOFF face (Python dependencies: `pillow`, `fonttools`). Source choices and fallback reasons are recorded in `scripts/figures/placeholder-section-art.json`. Regenerating also writes the guarded SQL; neither operation runs SQL.

Migration `20261120066500_placeholder_section_art.sql` fills only SQL NULL art in matching published/draft chapter sections: 13 Retina, 10 Attention, 7 Stress. It leaves authored art, other chapter sections, archived content, prose, figures and review feedback alone, and can be re-run safely. It requires the schema migration `20261120066300`. Deploy these assets **before** applying the seed to avoid image 404s: code works before the seed with the existing plain contents; older code understands the art records after the seed and still shows the burned-in mark, even without the new tag. No production migration or deployment is part of this PR.

Browser verification runs against the Vite development server, samples each figure's registered ScrollTrigger window (including authored holds), and asserts the expected pane record before comparing mounted figures. It uses a dated anonymous GET export and `page.route` to overlay section art in the real reader, with all database mutations blocked: `SECTION_ART_FIXTURE=/path/live.json node scripts/placeholder-section-art-browser.mjs`. It checks Chromium and WebKit at 1440, 1024 and 390, desktop contents fitting/hover, cards between sections but absent from back matter, inline mobile figures, equal mounted figure sets before/after, overflow and console errors. Evidence and the contact sheet are in `/Volumes/Brain/artifacts/retina-cleanup/65/`. PGlite executes the actual SQL in isolation; Storybook contains explicit placeholder contents/card states.
